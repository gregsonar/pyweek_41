# [PyWeek 41] Working Title: INTO THE DARK by Knotty Kaa

[Knotty Kaa entry](https://pyweek.org/e/KnottyKaa41/)


## Install requirements and launch:

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate.bat
pip install -r requirements.txt
python run.py
```
